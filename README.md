# 🚗 ROS 2 Smart Parking & E-Stop System (Mac + Docker)

## 프로젝트 소개
이 프로젝트는 ROS 2 Nav2와 Gazebo 시뮬레이션을 활용한 자율주행 스마트 주차 시스템입니다. 맥북의 하드웨어(웹캠, 아두이노)와 격리된 Docker 컨테이너(ROS 2) 간의 통신 제약을 극복하기 위해 **텍스트 파일 기반의 우체통(Mailbox) 브릿지 아키텍처**를 적용한 것이 특징입니다.

카메라로 ArUco 마커를 인식하여 로봇에게 주차 좌표를 전송하고, 물리적인 아두이노 버튼을 통해 위급 상황 시 자율주행을 즉각 차단하는 시스템이 통합되어 있습니다.

## 주요 기능
* **👁️ 비전 기반 자율 주차 (ArUco Vision Navigation)**
  * 맥북 웹캠을 통해 ArUco 마커를 실시간 스캔.
  * 마커 ID에 맵핑된 주차장 좌표를 계산하여 ROS 2 Nav2 목적지로 자동 전송.
* **🛑 하드웨어 긴급 정지 (100Hz E-Stop Override)**
  * 아두이노 물리 버튼 입력 감지.
  * 자율주행 제어 명령(`cmd_vel`)을 압도하기 위해 100Hz 속도로 정지 신호를 발행하여 로봇 강제 제동.
* **🐳 Mac-Docker 우체통 브릿지 (Mailbox IPC)**
  * Docker 환경에서 호스트(Mac)의 USB 및 카메라에 직접 접근하기 어려운 문제를 해결.
  * 호스트 장비의 Python 코드가 신호를 텍스트 파일에 기록하고, Docker 내부의 Bridge Node가 이를 읽어 ROS 2 Topic으로 변환.

## 🛠️ 시스템 아키텍처 및 폴더 구조
```text
📦 SmartParking_workspace
 ┣ 📂 ros2-web/ros2_workspace/src/parking_world
 ┃ ┣ 📜 mac_parking_vision.py  # [Mac] 카메라 구동 및 마커 인식 우체통 기록
 ┃ ┣ 📜 mac_arduino_estop.py   # [Mac] 아두이노 시리얼 통신 및 우체통 기록
 ┃ ┣ 📜 vision_bridge_node.py  # [Docker] 비전 우체통 수신 및 Nav2 목적지 전송
 ┃ ┣ 📜 estop_bridge_node.py   # [Docker] E-Stop 우체통 수신 및 강제 정지 명령 하달
 ┃ ┣ 📜 mac_run.sh             # [Mac] Mac 측 센서/하드웨어 일괄 가동 스크립트
 ┃ ┗ 📜 docker_run.sh          # [Docker] Docker 측 브릿지 노드 일괄 가동 스크립트
```
## ⚠️ 트러블슈팅

### 1. 🤯 맥북 하드웨어(웹캠/아두이노)가 도커 안의 ROS 2와 연결 안 되는 문제
* **증상:** 맥북 환경에서 Docker 컨테이너를 띄우니, 도커 내부에서 맥북의 웹캠이나 USB(아두이노) 포트를 직접 인식하지 못하는 치명적인 문제가 발생했습니다.
* **해결책:** 직접 연결을 포기하고 **'텍스트 파일 우체통(Mailbox)'**를 고안했습니다. 맥북(호스트)에서 파이썬 코드를 돌려 센서 값을 txt 파일로 저장하고, 도커 내부의 브릿지 노드가 이 파일을 0.1초마다 읽어서 ROS 2 토픽으로 변환(`publish`)하도록 우회하여 완벽하게 해결했습니다.

### 2. 🛑 정지 버튼을 눌렀는데 로봇이 멈추지 않고 덜덜거리며 계속 움직일 때
* **증상:** 아두이노 긴급 브레이크 버튼을 누르면 통신은 정상적으로 가는데, 가제보 안의 로봇이 완전히 멈추지 않고 마치 브레이크가 고장 난 것처럼 덜덜거리면서 주차 칸으로 억지로 끌려갔습니다.
* **원인:** 자율주행 두뇌인 Nav2가 "앞으로 가!"라고 명령하는 것과, 제 브레이크 노드가 "멈춰!"라고 명령하는 것이 `/cmd_vel` 토픽 안에서 서로 멱살잡이를 하며 충돌했기 때문이었습니다.
* **해결책:** Nav2를 완전히 제압하기 위해 브레이크 명령 발행 주기(Hz)를 극한으로 끌어올렸습니다. `estop_bridge_node.py`에서 정지 신호를 **1초에 100번(100Hz)**씩 폭격 수준으로 난사하도록 `timer`를 `0.01`로 설정하여, Nav2의 명령을 완전히 덮어씌워버렸습니다.

### 3. 🔌 아두이노 시리얼 포트 변동 및 통신 깨짐 에러
* **증상:** 맥북에 아두이노를 뺐다 꽂을 때마다 파이썬 코드에서 `[Errno 2] No such file or directory` 에러가 나거나, 통신은 연결됐는데 `UnicodeDecodeError`가 터지면서 정체불명의 외계어 문자가 찍혔습니다.
* **해결책:** 1. **포트 이름 변경 대응:** 맥북은 연결할 때마다 USB 번호가 바뀝니다. 터미널에 `ls -l /dev/cu.usb*`를 쳐서 현재 연결된 진짜 포트 이름을 찾은 뒤 파이썬 코드의 `PORT` 변수를 그때그때 수정했습니다.
  2. **외계어 및 디코딩 에러 방어:** 아두이노 스케치의 보드레이트와 파이썬 코드의 보드레이트를 똑같이 `115200`으로 통일했습니다. 또한 연결 직후 튀는 노이즈 데이터를 무시하기 위해 파이썬 디코드 부분에 `errors='ignore'` 옵션을 추가해 에러로 튕기는 현상을 막았습니다.
